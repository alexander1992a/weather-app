# Weather App (App de Clima)

Aplicación web interactiva que consume una API pública de clima para mostrar el estado del tiempo actual y pronóstico según la ciudad consultada. Desarrollada como parte del curso Trainee.

## Tecnologías utilizadas
- HTML5 y CSS3
- JavaScript (Vanilla) con `fetch` y `async/await`
- OpenWeather API

## Cómo ejecutarlo localmente
1. Clonar el repositorio.
2. Configurar tu API Key de OpenWeather en el archivo de configuración correspondiente.
3. Abrir `index.html` en el navegador.
